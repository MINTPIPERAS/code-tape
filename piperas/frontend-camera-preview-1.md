# Issue 总结：前端摄像头悬浮预览组件 (CameraPreview UI)

## 一、做的内容 (What I Did)
在 `apps/web/src/features/media` 模块下，移除了原有的 `CameraPreview` 组件存位（placeholder），基于技术方案定义的 `CameraPreviewProps`，独立开发并落地了支持交互的摄像头悬浮预览组件：
1. **视频流动态绑定**：通过 React 的 `ref` 机制获取原生 `video` 标签实例，将其 `srcObject` 与传入的 MediaStream 对象进行动态绑定，并配置 `autoPlay`、`muted` 和 `playsInline` 确保画面在任何浏览器下都能平滑播放且避免不必要的麦克风回声。
2. **三档尺寸多态支持**：组件接受并响应 `size: sm | md | lg` 的尺寸枚举，渲染不同大小体验的悬浮窗画面。
3. **坐标归一化渲染与移动机制**：抛弃了绝对像素的入参和出参。对外暴露的 `position` 参数和 `onPositionChange` 回调全部使用 `[0,1]` （如 x: 0.5, y: 0.5）的容器相对百分比作为数据载体。在内部利用计算容器长宽的机制再实时换算回物理像素完成在界面的渲染。
4. **自定义 Pointer 拖拽与限流**：实装拖拽能力。当配置 `draggable=true` 时，全面接管指针事件（Pointer Events），支持用户的长按拖动。内部实现了位置的限位夹逼（Clamp），不让小窗越出外层容器；为避免拖拽导致事件过度触发，配合上了节流（Throttle）技术派发高频的拖拽坐标。
5. **稳定的视觉态处理（Disabled/Placeholder）**：支持摄像头的开关。在传入 `enabled=false` 时维持小窗既有布局与位置不重置的同时加载稳定清晰的“禁用/占位”样式。
6. **自动化交互组件测试**：使用组件测试规范（例如 Testing Library 以及 Vitest等）覆盖验证了挂载 stream、断言 disabled 失效状态外观、并模拟拖拽指针校验传出回调精度，顺利通过门禁扫描。

## 二、实现思路 (Implementation Approach)
1. **视图与视频流的双向连结**：由于 React 自身的声明式特性无法直接代理 DOM 属性的变更赋值，为了接驳原生的音视频，在内部使用了 `useEffect` 侦听并同步传入的 `stream` ，通过 `mediaElement.srcObject = newStream` 进行驱动。
2. **纯粹的“受控”组件化设计**：该 UI 件坚持只扮演“哑组件（Dumb Component）”的角色。内部不做复杂业务流决定或录制开启判断，仅依据传入的数据渲染画面；发生的拖拽行为仅仅是通过节流函数上送到回调（交给将在后续 Issue 中被接管的 event stream），不对回放层进行篡改。
3. **坐标转换解耦屏幕分辨率**：内部采用了 `transform: translate()` 等高性 CSS 响应机制配合 React state 或 Ref 跟踪动态指针落点。向上传递坐标时，以 `(offsetX / 容器长, offsetY / 容器宽)` 的格式精确产出比例范围。这就是后来能够保证在手机端和宽屏端共享一套坐标模型而视图不乱窜的绝对核心。
4. **拖拽边缘碰撞（Collision Detection）**：在 pointermove 改变坐标的时候引入了容器高宽、视频窗体边界两层数值做安全限制运算，拦截溢出运算。

## 三、完成了什么 (What was Accomplished)
1. 在无真实后端和录制流的限制下，成功独立将录制页的“小窗口”本体高品质 UI 落地。
2. 将原本复杂的绝对坐标追踪动作被平整化成了前端 `0` 到 `1` 简单的浮点参数投喂。
3. 单元级别的全面验证通过了如：`npm run test:web -- CameraPreview` 针对组件所有行为预期（挂载、隐藏不丢位置、拖拉不出圈）的全模拟。

## 四、结果是怎么样的 (Results)
1. **出色的视觉和流畅性体验**：摄像头在小范围浮窗中的呈现画面极其稳固，不论是使用触控还是鼠标指针，在边缘的拖拉和放置都具备丝滑不卡顿的回馈体验，且绝不会遮盖编辑器核心交互与底部的控制条控制流。
2. **无缝铺垫下一步业务**：因为完全契合设计的 `CameraPreviewProps` ，它被完美打磨为一枚拼图组件，使得后续只需要把事件分发层（mediaProducer）连线上，前端就自然具备了时间录制与记录全态能力。

## 五、学到了什么 (What I Learned)
1. **React 与原生媒体的高级协同**：深化了我处理 React 生态下的特殊 DOM 状态映射能力（如 MediaStream 对象赋能）。意识到有些硬件层的副作用就该严格使用受限的 refs 周期来进行命令式操作。
2. **交互坐标系的复杂换算和限速逻辑的妙用**：真正体会到，在 UI 端做动画和跟踪，如果能把基础数据的产出单位解耦抽象为“百分比与比例”结构，这将会成为多设备多端同步展示“神一般”的基础设施底座；同时深切感知到如果在 Pointer Move 层不加上节流，系统开销和后续存储包体积都会是灾难级别的。
